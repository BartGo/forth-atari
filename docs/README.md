# docs/

Texts kept next to the APX fig-Forth snippets. They are not loadable APX screens.

| File | What it is | Relation to this repo |
|------|------------|------------------------|
| `ATARI-CONCEPTS.txt` | Extract from `figasm, f69asm, computype master.atr` (Atari coin-op development notes). Inverse video and Atari characters did not convert cleanly. | Forth in that document is a DECUS/PDP-11-derived in-house system (terminal / analyser / GIB), not APX on the 8-bit home computer. |
| `tinybasicinforth.txt` | Archive grab of “Tiny BASIC in Forth” (1984, Forth-83 style: `ONLY` / `ALSO`, `ABORT"`, `+THRU`). Still contains the original email wrapper. | **Will not run on APX fig-Forth.** Kept as a reference dump only. |
